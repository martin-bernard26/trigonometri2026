⚙️ Panduan Setup Firebase (untuk dosen)

▾
  1. Buka Firebase Console, buat proyek baru (gratis, paket Spark).
  2. Di menu kiri pilih Build → Realtime Database → Create Database → pilih lokasi server → mulai dalam mode test.
  3. Salin URL database yang tampil di bagian atas halaman (bentuknya seperti https://nama-proyek-default-rtdb.asia-southeast1.firebasedatabase.app, atau alias lama https://nama-proyek-default-rtdb.firebaseio.com).
  4. Tempelkan URL tersebut ke variabel FIREBASE_DB_URL di bagian atas kode ini.
  5. Buka tab Rules, gunakan aturan berikut agar node diskusi bisa diakses publik tanpa autentikasi: 
    {
  "rules": {
    "diskusi": {
      ".read": true,
      ".write": true
    }
  }
}
  6. ⚠️ Aturan ini terbuka bagi siapa pun yang tahu URL-nya — cukup aman untuk diskusi kelas jangka pendek, tetapi jangan simpan data sensitif. Nonaktifkan Rules setelah semester selesai.
  7. Tidak perlu firebase-admin SDK maupun API key — halaman ini hanya memakai fetch() biasa ke REST API Firebase.
