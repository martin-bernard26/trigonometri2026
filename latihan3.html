Unggah PDF ke Google Drive & Kirim

Pastikan catatan Anda sudah berbentuk satu berkas PDF sebelum mengikuti langkah ini.
  1. Buka drive.google.com dan masuk dengan akun Google Anda.
  2. Unggah berkas PDF catatan Anda ke Drive.
  3. Klik kanan file tersebut → Dapatkan link → ubah akses menjadi "Siapa saja yang memiliki link" → Salin link.
  4. Tempelkan link tersebut pada kolom di bawah, lalu kirim.
Lengkapi semua data lalu tekan "Kirim Tugas".

Panduan Dosen: Menghubungkan Formulir Ini ke Google Form & Google Sheet

▾
  1. Buat Google Form dengan field short answer berurutan: Nama, NIM, Kelas, Mata Kuliah, Judul/Topik Catatan, dan Link Google Drive.
  2. Hubungkan form ke Google Sheet lewat tab Responses → ikon Sheets.
  3. Ambil entry ID tiap field lewat menu titik tiga pada form → Get pre-filled link → isi tiap field dengan teks unik → Get link → salin pola entry.123456789 dari URL yang dihasilkan untuk tiap field.
  4. Ambil URL pengiriman form: lihat sumber laman untuk <form action="https://docs.google.com/forms/d/e/XXXX/formResponse">, atau ganti akhiran /viewform pada URL form menjadi /formResponse.
  5. Buka bagian <script> file ini, cari GOOGLE_FORM_CONFIG, lalu isi formActionUrl dan seluruh entries.*. Contoh: 
    const GOOGLE_FORM_CONFIG = {
  formActionUrl: "https://docs.google.com/forms/u/0/d/e/.../formResponse",
  entries: {
    nama:  "entry.1",
    nim:   "entry.2",
    kelas: "entry.3",
    mk:    "entry.4",
    topik: "entry.5",
    link:  "entry.6"
  }
};
  6. Bagikan file HTML ini ke mahasiswa (unggah ke Google Classroom / Google Sites / LMS). Berkas PDF mahasiswa tidak pernah melewati server manapun selain Drive mahasiswa itu sendiri — halaman ini hanya mengirim data teks (identitas + link) ke Sheet.
